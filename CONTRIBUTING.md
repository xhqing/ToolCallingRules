Thank you for your interest in contributing to Tool Calling Rules! This document provides guidelines and instructions for contributing to this project.

## How to Contribute

### 1. Report Issues

If you find any problems with the rules or documentation:

- Search existing issues to avoid duplicates
- Open a new issue with a clear title and detailed description
- Provide specific examples or use cases when possible

### 2. Propose New Rules or Changes

Before making significant changes:

- Open an issue to discuss your proposed changes
- Explain the problem your changes address
- Provide concrete examples of how the changes improve tool calling behavior

### 3. Submit Pull Requests

When submitting a pull request:

- Fork the repository and create a feature branch
- Keep changes focused and atomic (one feature/fix per PR)
- Update both English and Chinese versions if modifying rules
- Write clear commit messages
- Reference related issues in your PR description

### 4. Translation Contributions

This project maintains both English and Chinese versions:

- Ensure translations accurately reflect the original meaning
- Maintain consistent terminology across both versions
- Update corresponding files in both languages when making changes

## Code of Conduct

- Be respectful and constructive in discussions
- Focus on improving the quality and clarity of the rules
- Welcome feedback and alternative perspectives

## Questions?

If you have any questions about contributing, feel free to open an issue for discussion.
